## 📌 About The Project

Welcome to the **HTML Course & Developer Portfolio** repository! This project serves as a comprehensive web portfolio designed and developed by **Beemaneni Venkata Siddartha**. It highlights core web development competencies, hands-on HTML5 & CSS3 coursework, interactive components, responsive page design, and multimedia integration.

---

## ✨ Features

- 🏠 **Home Page (`index.html` / `Home.html`)**: Introduces the developer with quick navigation, hero video/image showcase, and direct action buttons.
- 👤 **About Page (`about.html`)**: Features developer biography, background video, and learning resources.
- 🛠️ **Skills Showcase (`skills.html`)**: Categorized breakdown of Technical Skills (HTML5, CSS3, JavaScript, C Programming) and Soft Skills (Communication, Teamwork, Problem Solving, Time Management).
- 📂 **Projects Page (`project.html`)**: Interactive showcase cards with direct live GitHub repository links and preview images.
- 📬 **Contact Page (`contacts.html`)**: Contact form, direct email, phone details, and location.
- 📱 **Responsive & Styled**: Custom CSS styling with background aesthetics, interactive buttons, and navigation.

---

## 🛠️ Built With

- **HTML5** – Semantic structure, audio/video embeds, and forms.

- **JavaScript** – Dynamic client-side logic and interactions.

## 🚀 Getting Started Locally

To run this project on your local machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/SiddarthaBeemaneni/HTML-course.git
   ```

2. **Navigate into the directory:**
   ```bash
   cd HTML-course
   ```

3. **Open the project:**
   - Double-click `index.html` or `Home.html` to open directly in any web browser, OR
   - Use VS Code Live Server extension: right-click `index.html` -> **"Open with Live Server"**.
